CFNM

CFNM commonly means “clothed female, naked male.” It is an established niche acronym used to describe a particular adult or fetish context.

Scope: This page explains terminology and online usage. It does not host or reproduce adult material.

Definition

The acronym is primarily useful as a terminology label. Context matters because publishers, communities and search users can use niche labels somewhat differently.
