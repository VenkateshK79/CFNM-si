CFNM Terminology Guide

CFNM is an initialism whose letters describe a clothing contrast. Different references use both “naked” and “nude” for the N, while the underlying acronym remains recognizable.

CFNM

Commonly: Clothed Female, Naked Male. Some references use “Clothed Female, Nude Male.”

CMNF

Commonly: Clothed Male, Naked Female. It is often presented as the counterpart to CFNM.

CFNM content

A broad classification used by publishers, communities or creators for material associated with the CFNM term. Exact classification practices can differ between sites.

CFNM community

A general description for audiences or online communities interested in the niche. It does not identify one particular organization.

CFNM domain

A domain containing the acronym. CFNM.si is a four-letter example available for acquisition.
