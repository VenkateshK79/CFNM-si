Data layer

Adult Web Observatory

The data layer is designed to make public internet-interest research reproducible, source-aware and honest about uncertainty.

Primary planned sourceGoogle Trends public BigQuery datasets: anonymized, indexed, normalized and aggregated trend data.
Stored dimensionsTerm, terminology group, country, region, search property, category, period and granularity.
Stored provenanceSource, retrieval time, source URL and collection method accompany observations.
Explicit exclusionsNo personal search histories, private analytics, inferred gender, inferred sexuality, or absolute search counts derived from normalized scores.
Current statusSchema and BigQuery query layer are prepared. Live scheduled ingestion requires a Google Cloud/BigQuery connection; credentials are not stored in this repository.

Why this matters

Keeping raw source fields and provenance makes it possible to audit a chart later instead of presenting a number without knowing where it came from.
