CFNM Glossary

A simple reference for terminology surrounding the CFNM acronym.

CFNM

Commonly means “clothed female, naked male.” It describes a clothing-based adult/fetish scenario and is used as a niche acronym.

CFNM content

A broad description for adult material categorized using the CFNM term. Exact usage varies between publishers and communities.

CFNM community

A general phrase for online communities or audiences interested in the CFNM niche. It does not refer to one specific organization.

CFNM creator

A creator whose work includes material categorized or marketed using the CFNM term.

CFNM domain

A web domain containing the CFNM acronym. CFNM.si is a four-letter example currently offered for acquisition.
